## 4. Композиционные ограничения

Со слов заказчика:
- первый экран не перестраивать, заголовок не заменять;
- паттерны — часть визуальной идентичности, но текст не диктуют;
- не заменять визуальную концепцию стандартными карточками образовательного лендинга (29.10);
- карточки случаев не прятать в раскрытие целиком — истории видны полностью (решение
  по тексту, влияет на композицию).
