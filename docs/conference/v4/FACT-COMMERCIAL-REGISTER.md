# Fact & Commercial Register · Конференция случаев 2027

**Подтверждают ответственные за продукт и продажи.** Регистр составил редактор по
источникам; ни одна позиция редактором не утверждена.

**Источники:** **В** — человеческая вычитка «3(1).docx» и Google Doc с комментариями;
**М** — маркетинговая редакция от 29.10; **ОД** — таблица «Конференция случаев 2027:
основной документ»; **П** — документ позиционирования «Конференция случаев 2027, МИГ».

**Статусы:** не подтверждено · противоречие (источники расходятся) · подтверждено ·
решено (решение принято, указано кем).

## Первый экран: проверить, когда будет текст макета

Визуальное утверждение не подтверждает факты. Текста макета у редактора нет, поэтому ниже —
условия, а не выводы: **если** в макете есть формулировка из левой колонки, это вопрос
по указанной позиции регистра. Если формулировки в макете нет, проверять нечего.

| Если в макете есть | Почему это вопрос | Позиция |
|---|---|---|
| эксперты в каждом случае, «шесть взглядов», «команда из шести» | эксперты подтверждены не во всех случаях | Р-10 |
| «24 спикера» | неясно, кого считать | Р-06 |
| «5 конференция подряд» | непрерывность не подтверждена | Р-18 |
| «лекции без скучной теории» | заказчик решил: «2 специальные лекции» (30.10) | решено |
| записи «в личном кабинете», состав или сроки записей | заказчик решил: только «Записи конференции будут доступны после мероприятия» (30.10) | решено |
| сертификат вместе с записями или с EAGT | заказчик решил: сертификат отдельно, только в подтверждённом тарифе; EAGT без подтверждения не упоминается | решено; Р-19 |
| цена или дата на кнопке | цены и границы ступеней не подтверждены | Р-01, Р-02 |
| «Забронировать участие» | неясно, к оплате или к брони | Р-05 |

## Решено

| Что | Решение | Кто, когда |
|---|---|---|
| Записи | на сайте только «Записи конференции будут доступны после мероприятия»; подробности — отдел продаж | заказчик, 30.10 |
| «Кибермощь» | не публикуется; из продукта не исключена | заказчик |
| Сертификат | отдельно от записей, только в подтверждённом тарифе; без EAGT до подтверждения | заказчик |
| Эксперты | не обещать экспертов в каждом случае до подтверждения состава | заказчик, 30.10 |
| Лекции в статистике | «2 специальные лекции» | заказчик, 30.10 |
