## 4. Чего в архиве действительно нет

Проверила — этих данных нет ни в одном из репозиториев:

1. **Конверсии по этапам воронки Базового курса** — есть по ППК, по БК нет.
2. **Сквозная аналитика от клика до оплаты.**
3. **Данные по португальскому потоку** — сентябрьский набор, который не состоялся.
4. **Размер аудитории по гео в рекламных кабинетах.**
5. **Статистика по блогерам** — та, что мы запрашиваем сейчас.

## 5. Что с этим делать дальше

1. **Свести цены специализаций из каталога на карточки сайта.** Блокер P0-2
   оказался не «цен нет», а «цены есть, но не на витрине». Это меняет задачу
   с «запросить у продаж» на «опубликовать».
2. **Пересчитать сентябрьский план с рекламным фондом 25 000 €** — раньше
   бюджет был неизвестен, планирование шло от логики распределения.
3. **Прочитать `mig-audience-past-cohorts.md` перед следующим набором.**
   Если прошлые потоки собирались из тёплых кругов преподавателей, то стратегия
   португальского набора должна начинаться с них, а не с блогеров.
4. **Не дублировать R02, R11 и R14** при любом новом разборе конкурентов.
