# R07. SEO-возможности

_Дата: 05.08.2026. Статус: выполнено._

## Как делал (метод)
Синтез данных технического аудита (audit_mig_institute.md), анализа спроса (R01) и структуры сайта (sitemap: 39 страниц, 220 товаров, ~15 статей). Оценка трафикового потенциала — по модели «кластер × частотность × достижимая позиция × CTR» с консервативными коэффициентами.

## Текущее состояние (факты из аудита)
- Индексация в порядке: sitemap-инфраструктура, canonical, hreflang, robots.txt — ✅
- Контент-сигналы провалены: нет H1/description на главной, пустые alt (38/38), стагнация блога с 11.2024 — ❌
- Скорость (Core Web Vitals): TTFB ~2 c, HTML 600+ КБ — прямой негативный фактор ранжирования — ❌
- При этом сайт УЖЕ ранжируется по категорийным запросам (продуктовая страница БК найдена в органике, R01) — значит, домен имеет базовое доверие; рост возможен без линкбилдинга с нуля.

## Расчёт трафикового потенциала (12 месяцев работ)

Модель: Трафик = Σ по кластерам (частотность × достижимая доля показов × CTR позиции).
Допущения: достижимые позиции 3–10 по СЧ/НЧ за 6–12 мес при 2–4 статьях/мес + техфиксы; CTR позиций 3–10: 2–8%.

| Кластер (из R01) | Частотность, мес | Достижимая доля × CTR | Трафик/мес через 12 мес |
|---|---|---|---|
| Информационный широкий («что такое гештальт…») | 100 000+ | 1–3% | 1 000–3 000 |
| Карьерный («как стать терапевтом») | 5 000–20 000 | 4–8% | 200–1 600 |
| Коммерческий («обучение гештальт-терапии») | 3 000–10 000 | 3–6% | 90–600 |
| Диаспорный («обучение на русском в Европе») | 300–1 500 | 15–30% (низкая конкуренция) | 45–450 |
| Повышение квалификации | 1 000–5 000 | 5–10% | 50–500 |
| **Итого** | | | **~1 400–6 100 визитов/мес** (центр: ~3 000) |

Конверсия SEO-трафика в лид (форма/подписка/ДОД): 1–2,5% → **30–75 лидов/мес** к 12-му месяцу, себестоимость лида → 0 в пределе (против 20 € в перформансе).

## Приоритетные работы (по влиянию/усилию)
1. **Техфиксы** (1–2 недели): H1/title/description, кеширование, lazy load — без них контент не даст эффекта.
2. **Коммерческие посадочные** под кластеры: «обучение гештальт-терапии онлайн», «обучение для русскоязычных в Европе» (диаспорная — почти без конкуренции), «супервизия», «ППК».
3. **Контент-конвейер**: 2–4 статьи/мес; авторы-преподаватели = E-E-A-T сигналы (экспертность автора — фактор Google для YMYL-тематик, психотерапия — YMYL).
4. **Реанимация существующих 15 статей**: обновить даты/контент — быстрее, чем писать с нуля.
5. Schema.org Course/Event на 220 товаров → расширенные сниппеты.

## Экономический эквивалент (метод расчёта)
3 000 визитов/мес × эквивалентная цена клика 0,5 € = 1 500 €/мес бесплатного трафика; 40 лидов/мес × 20 € = 800 €/мес сэкономленного CPL. Стоимость производства: ~1 000–2 000 €/мес (копирайтер + редактор + SEO-специалист на парт-тайме). **Окупаемость канала: 12–18 мес, далее — актив с почти нулевой предельной стоимостью лида.**

## Выводы
SEO для МИГ — не быстрый канал, а стратегический актив с лучшей в портфеле предельной экономикой. Уникальная возможность — диаспорный кластер: конкуренции почти нет, а это самая маржинальная аудитория института.
