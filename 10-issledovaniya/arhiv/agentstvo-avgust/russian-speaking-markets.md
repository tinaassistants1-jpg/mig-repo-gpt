# Карта русскоязычных рынков: где давать рекламу

Для клиента МИГ (и будущих клиентов-психологов). Аудитория — русскоговорящие
в любой стране, особенно психологи/психотерапевты.
Дата проверки источников: **2026-08-05**.

## Сводная карта аудиторий

### Кластер 1: Россия (самый большой рынок)
Каналы: только VK Реклама, Яндекс Директ, Telegram Ads, посевы
(Meta не показывает рекламу в РФ, Google Ads не работает).

### Кластер 2: Релокантские хабы (волна 2022+)
Всего уехало ~666–900 тыс. человек ([Re:Russia](https://re-russia.net/en/review/347/), [The Bell](https://www.intellinews.com/666-000-russians-have-emigrated-since-early-2022-the-bell-333948/)):

| Страна | Оценка русскоязычных релокантов | Примечание |
|---|---|---|
| Сербия | ~220 тыс. приехало в 2022, 30 тыс. ВНЖ к 2023 ([The Insider](https://theins.press/en/economics/294913)) | У МИГ уже есть Базовый курс |
| Черногория | 113+ тыс. регистраций в 2022 | Юрлицо клиента здесь |
| Армения | ~108–110 тыс. (2022) | |
| Грузия | ~62–74 тыс. (2022) | |
| Также: Турция, Кипр, ОАЭ, Таиланд/Бали, Аргентина, Казахстан | десятки тысяч в каждой | Точных публичных цифр меньше |

**Почему кластер ценный:** среди релокантов непропорционально много
психологов и их клиентов; спрос на психподдержку в эмиграции высокий;
психологи-эмигранты потеряли локальный рынок и нуждаются в международных
аккредитациях (EAGT/EAP — сильная сторона МИГ) и профессиональном комьюнити.

### Кластер 3: Классическая диаспора
Источники: [Wikipedia: Russians in Israel](https://en.wikipedia.org/wiki/Russians_in_Israel), [обзоры русскоязычных стран](https://www.fluentu.com/blog/russian/countries-that-speak-russian/):

| Страна | Русскоязычных | Примечание |
|---|---|---|
| Израиль | ~1,3 млн (15% населения) | Много специалистов помогающих профессий; высокая платёжеспособность |
| Германия | ~3 млн | Крупнейшая диаспора Западной Европы |
| США/Канада | ~1 млн+ | Высокий чек, но дорогая реклама |
| Латвия | ~0,5 млн (25–30%) | + Эстония, Литва |
| Португалия/Испания | растущие сообщества | У МИГ курс в Португалии |

### Кластер 4: СНГ (кроме РФ)
Казахстан (~3+ млн говорящих по-русски, Meta/Google работают!), Беларусь,
Узбекистан, Кыргызстан, Азербайджан, Молдова. Казахстан — самый интересный:
большая аудитория + работают западные рекламные площадки + своя волна
психологизации.

### Осторожно: Украина
На сайте МИГ есть украинская версия, но реклама русскоязычного института
на Украину сейчас несёт высокие репутационные и модерационные риски.
Решение — только с клиентом, не по умолчанию.

## Практические выводы

1. **Один Meta-кабинет закрывает кластеры 2–4** (всё, кроме РФ): таргетинг
   «язык: русский» + гео-пакеты. Это главное преимущество черногорского
   юрлица клиента.
2. **Приоритет гео-пакетов для Meta-теста** (по совпадению аудитории
   и продукта):
   - Пакет A «Балканы»: Сербия + Черногория (курс МИГ уже там, локальное
     событие = сильный оффер);
   - Пакет B «Хабы»: Грузия, Армения, Кипр, Турция (онлайн-формат);
   - Пакет C «Диаспора»: Израиль, Германия (для ППК/супервизии — там
     платёжеспособные практикующие психологи);
   - Пакет D «СНГ»: Казахстан (масса + дешёвые показы).
3. **РФ — отдельная машина** (VK/Яндекс/Telegram) — не смешивать
   с международной ни в бюджете, ни в креативах.
4. Для будущих клиентов-психологов эта же карта = карта их клиентов
   (русскоязычные в эмиграции ищут терапевтов на родном языке).

## Пробелы (честно)

- Нет публичной статистики «сколько именно психологов» по странам —
  оценим косвенно из первых кампаний (стоимость лида по гео покажет
  плотность аудитории).
- Цифры релокации 2022–2023 частично устарели к 2026 (часть вернулась,
  часть переехала дальше) — тест покажет актуальную картину.
