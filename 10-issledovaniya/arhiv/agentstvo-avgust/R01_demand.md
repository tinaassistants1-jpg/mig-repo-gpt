# R01. Анализ спроса на обучение гештальт-терапии

_Дата: 05.08.2026. Статус: выполнено._

## Как делал (метод)
1. Серия поисковых запросов по категории «обучение гештальт-терапии» (Google, рус.) — анализ состава выдачи: кто ранжируется, сколько игроков, есть ли агрегаторы.
2. Кластеризация спроса на семантические группы по логике воронки (осведомлённость → интерес → выбор → покупка).
3. Оценка частотности — экспертные диапазоны на основе структуры выдачи и количества конкурирующих предложений. Прямой доступ к Яндекс.Wordstat/Google Keyword Planner из среды исследования отсутствовал — все цифры помечены как «оценка», метод верификации указан.

## На что опирался (данные)
- Выдача по запросу «обучение гештальт-терапии базовый курс стоимость»: 7+ уникальных доменов-конкурентов, включая агрегаторы ([b17.ru](https://www.b17.ru/trainings/1-stupen-gestalt/), [okursah.ru — «ТОП-28 курсов гештальт-терапии в Москве»](https://moscow.okursah.ru/kursy/geshtalt-terapiya)).
- Факт: страница МИГ (mig.institute/product/bk-…) появилась в органической выдаче по категорийному запросу — сайт индексируется и способен ранжироваться, несмотря на технические проблемы (см. audit_mig_institute.md).
- Наличие 28 курсов в одном только московском агрегаторе — маркер зрелого, конкурентного и подтверждённого спроса.

## Структура спроса (кластеры)

| Кластер | Примеры запросов | Этап воронки | Оценка частотности (RU, в мес.) | Коммерческая ценность |
|---|---|---|---|---|
| Информационный широкий | «гештальт терапия что это», «закрыть гештальт» | Осведомлённость | 100 000+ (высокочаст.) | Низкая напрямую, высокая для контент-воронки |
| Карьерный | «как стать гештальт-терапевтом», «профессия психолог с нуля» | Интерес | 5 000–20 000 | Высокая |
| Образовательный коммерческий | «обучение гештальт терапии», «курсы гештальт терапевта онлайн», «гештальт институт» | Выбор | 3 000–10 000 | Очень высокая |
| Брендовые конкурентов | «МГИ обучение», «МИГиП 1 ступень» | Выбор | 2 000–8 000 | Высокая (перехват сравнением) |
| Диаспорный | «обучение психотерапии на русском в Европе», «гештальт обучение из-за границы» | Выбор | 300–1 500 (низкочаст.) | Критически высокая для МИГ: минимальная конкуренция |
| Повышение квалификации | «супервизия гештальт», «курс психосоматика для психологов» | Покупка (практики) | 1 000–5 000 | Высокая, короткий цикл сделки |

## Метод расчёта оценок
Диапазоны частотности получены триангуляцией: (а) число и тип конкурентов в выдаче (агрегаторы заходят в ниши от ~3–5 тыс. запросов/мес); (б) соотношение широких и узких запросов в тематике психологии (типично 20:1); (в) публичные данные о том, что тематика «психология» — одна из топ-5 в онлайн-образовании РФ. **Верификация:** снять точные частоты через Яндекс.Wordstat + Keyword Planner (30 минут работы при наличии аккаунтов) — рекомендуется до запуска контекстной рекламы.

## Выводы
1. Спрос подтверждён и зрелый: в нише есть агрегаторы — они не приходят в пустые ниши.
2. Для МИГ есть «голубой океан» — диаспорный кластер: запросы русскоязычных за пределами РФ, где московские институты слабы (им сложнее принимать платежи и давать очные модули в ЕС).
3. Самый недооценённый актив — информационный кластер (100K+ запросов/мес): при мёртвом блоге МИГ не получает почти ничего из этой воронки.
4. Быстрый спрос — кластер повышения квалификации: короткий цикл сделки, продукты уже есть (220 позиций каталога).
