## Постоянные факты — проверять перед любым планом

| | |
|---|---|
| **МИГ.ФЕСТ** | **Бесплатный. Открыт для всех. Лид-магнит входящей воронки.** Билетов нет, цены нет, срочности по цене нет |
| **Доход со студента БК** | 8 000 € за 4 года, **помодульно** — 36 платежей по 222 € |
| **Потолок CAC** | **280 € на платящего клиента.** Считается против первого модуля, а не против дохода за курс |
| **Потолок цены регистрации** | 4 € до измерения сквозной конверсии, далее до 6 € |
| **Потолок CPL участника ФЕСТа** | 1,4–2,8 €; платный холод почти не окупается, набор — бесплатными каналами |
| **Группа БК** | 18 человек · набор стоит 5 040 € · окупается за 1,26 модуля |
| **Вход в БК** | профильное высшее + 100 часов личной терапии — жёсткий фильтр |

**Главное правило бюджета:** при рассроченной оплате считаем от **скорости возврата**,
а не от суммы возврата. Расчёт от дохода за 4 года даёт кассовый разрыв.

**Тон коммуникации:** аудитория — психологи, они профессионально распознают манипуляцию.
Никаких фальшивых счётчиков, «последний шанс» и давления. Только настоящая срочность.

**Никаких выдуманных цифр.** В документах разделено: ФАКТ · ИНТЕРПРЕТАЦИЯ · ГИПОТЕЗА.
